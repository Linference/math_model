# 01 — 深度审题指南

审题是全部 7 阶段的"宪法"。审题报告的结论驱动后续所有决策——方法选型、数据需求、求解策略、论文结构——因此审题必须详尽、不可浓缩。

---

## ⛔ 审题深度原则

1. **宁可多拆、不可遗漏**：每一小问的子任务必须拆到"可独立分配执行"的粒度。
2. **隐性约束是区分高分与及格的关键**：题目没写但你踩了就扣分的规则，必须推导出来。
3. **审题报告不可浓缩**：阶段 1 产出至少 2000 字。后续阶段必须显式引用审题报告内容。
4. **思考链保留**：审题过程中的分析推理必须全部保留在 REPORT.md §1 中，不允许缩成一句话总结。

---

## 审题框架（7 个必答维度）

### 1. 背景与核心目标
- 一句话概括赛题要解决什么问题
- 成功的标准是什么（题目中暗示的评价标准）

### 2. 逐问拆解（每小问独立一段）

对每一小问：
```
**问题 X（小问标题）**
- **输入**：题目给了什么？需要什么？
- **输出**：要求产出什么？（数值/方案/图表/文字分析）
- **显性约束**：题目原文中的限制条件（逐条列出原文引用）
- **隐性要求**：题目没写但评分会扣的（推导依据）
- **与其它问的依赖**：需要前序问的结果吗？后续哪问依赖本问？
- **评分权重猜测**：核心问还是辅助问？
```

### 3. 显性约束清单（从题目原文逐句提取）

格式：
```
约束 C1：……（来源：题目第 X 段 "……"）
约束 C2：……
```

### 4. 隐性约束推导（最重要）

每条必须给出 **推导依据**：

| 隐性约束 | 推导依据 | 如果不遵守的后果 |
|---|---|---|
| 必须区分 Scope 1/2/3 排放 | 环境评估科学共识 + 题目要求"全面的环境影响" | 漏掉 Scope 3（观众旅行）→ 碳足迹低估 50%+ → 结论不可信 → 扣 15-20 分 |
| …… | …… | …… |

隐性约束的来源：
- **现实合理性**：模型假设必须符合物理/经济/社会常识
- **数据可获得性**：模型中用到的参数必须能实际获取
- **模型可求解**：模型复杂度不能超过可求解范围
- **评分标准暗示**：历年评分标准中反复强调的要素

### 5. 数据情况评估

- **题目直接提供**：文件名、格式、字段、量级、是否完整
- **需要自行获取**：数据名称、可能来源、获取难度（容易/中等/困难）
- **数据质量风险**：时效性、覆盖面、精度、单位统一性
- **如果数据不足的预案**：代理变量、合理假设、缩小范围

### 6. 评分点与陷阱

| 编号 | 陷阱描述 | 踩了会怎样 | 规避方法 |
|---|---|---|---|
| T1 | …… | 扣 X 分 / 结论不可信 / 模型不可复现 | …… |
| T2 | …… | …… | …… |

常见陷阱类型：
- **方法选择陷阱**：用错方法类型（如评价题用预测方法）
- **数据陷阱**：单位不统一、时间口径不一致、样本量不足
- **假设陷阱**：假设过于理想化、假设之间互相矛盾
- **结论陷阱**：结论超出模型适用范围、忽略不确定性
- **格式陷阱**：摘要无量化数字、图表无解读文字

### 7. ⛔ 问题类型判定（驱动后续全流程）

**在所有拆解完成后，必须对赛题整体做出类型判定，这是后续阶段选型的基础。**

#### 7.1 类型分类标准

| 类型 | 特征标志 | 典型关键词 |
|---|---|---|
| **优化类** | 目标函数 + 约束条件，求最大/最小/最优方案 | 最小化/最大化/最优/分配/调度/路径 |
| **评价类** | 多指标综合评价、排序、选择 | 评价/排名/选择/指标体系/综合得分 |
| **预测类** | 基于历史数据推断未来 | 预测/趋势/预报/估计/演变 |
| **机理类** | 基于物理/生物/经济规律建模 | 建立方程/机理/动力学/演化/传播 |
| **混合类** | 包含 ≥2 种上述类型的子问题 | 各小问类型不同 |

#### 7.2 判定依据（至少 3 条）

```
判定：本题为 ______ 类
依据 1：……
依据 2：……
依据 3：……
```

#### 7.3 类型对应的策略要点

| 类型 | 模型优先搜索方向 | 必备图 | 最容易犯的错误 |
|---|---|---|---|
| 优化类 | LP/IP → NLP → 启发式(GA/PSO/SA) | 收敛曲线、可行域、灵敏度龙卷风 | 忘了证明凸性/收敛性 |
| 评价类 | AHP/熵权 → TOPSIS → 灰色/模糊 | 权重图、排名图、雷达图、热力图 | 一致性检验不通过还硬用 |
| 预测类 | ARIMA → 回归 → ML(XGBoost/LSTM) | 拟合对比、残差、特征重要性 | 没做残差白噪声检验 |
| 机理类 | ODE → PDE → 系统动力学 → 元胞自动机 | 相图、参数敏感、时序曲线 | 没验证守恒律 |
| 混合类 | 各子问题分别选型 + 统一框架整合 | 各类型组合 | 子问题方法冲突 |
