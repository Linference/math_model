# 09 — 模型创新方法手册

创新不必是"发明新算法"。以下 12 种创新策略，按实施难度排序，每种都能在数学建模竞赛中显著加分。

---

## ⛔ 创新三原则

1. **创新必须有用**——不能为了创而创，每条创新必须在对比实验中证明价值
2. **创新必须可解释**——评委要能理解你做了什么、为什么更好
3. **创新要显式声明**——在摘要和模型评价中明确写出"本文的创新点在于……"

---

## 策略 1-4：低难度（任何题都能用）

### 1. 方法组合创新 ★☆☆☆☆
**描述**：将两种标准方法首次组合用于本问题。
**示例**：
- AHP 定权重 + TOPSIS 排序 → 组合为 AHP-TOPSIS
- 熵权法 + 灰色关联度 → 客观权重 + 关联排序
- ARIMA + GARCH → 均值预测 + 波动率建模

**加分方式**：对比单独用 A 方法和单独用 B 方法，证明组合后效果更好。

### 2. 改进创新 ★★☆☆☆
**描述**：对标准方法做一处针对性改进。
**示例**：
- 标准 TOPSIS 对逆序敏感 → 加入"锚点城市"防逆序漂移
- 标准 KMeans 需预设 K → 用肘部法则 + 轮廓系数自动选 K
- AHP 1-9 标度太粗 → 改用 1-5 标度 + 一致性自动调整

**加分方式**：对比改进前后的结果差异，证明改进解决了具体问题。

### 3. 视角创新 ★★☆☆☆
**描述**：从新角度定义问题，而非沿用常规思路。
**示例**：
- 选址问题常规是"最小化总成本" → 改为"最小化最大遗憾"（鲁棒优化视角）
- 评价问题常规是"综合得分排序" → 改为"淘汰制筛选 + 精选排序"
- 预测问题常规是"点预测" → 改为"区间预测 + 风险分级"

### 4. 验证创新 ★☆☆☆☆
**描述**：用创意验证方式增加论文说服力。
**示例**：
- 灵敏度分析不只是 ±20% → 蒙特卡洛全局敏感性分析（计算 Sobol 指数）
- 交叉验证不只是 k-fold → 留一城市验证（评估模型对样本组成的敏感性）
- 不只是与 1 个基准对比 → 3-5 个方法的"锦标赛"对比

## 策略 5-8：中难度（需要一定数学/编程能力）

### 5. 混合模型创新 ★★★☆☆
**描述**：不同方法论体系深度融合。
**示例**：
- 机理模型 + 数据驱动：用微分方程刻画核心动力学 → 用 ML 学习方程参数
- 优化 + 仿真：用优化找候选方案 → 用蒙特卡洛仿真验证稳健性
- 统计 + 图论：用回归找影响因素 → 用网络分析揭示因素间交互结构

### 6. 多阶段/多层创新 ★★★☆☆
**描述**：将单层模型扩展为多层递进结构。
**示例**：
- 单层 AHP → 双层 AHP（城市层 + 场馆层）
- 单目标优化 → 多目标优化 + Pareto 前沿分析
- 单次预测 → 滚动预测 + 预测区间随时间演化

### 7. 自适应/动态创新 ★★★★☆
**描述**：模型参数/结构随条件自适应调整。
**示例**：
- 固定权重 → 自适应权重（权重随城市类型/气候区域变化）
- 固定阈值 → 动态阈值（分类阈值随数据分布自适应）
- 静态网络 → 动态网络（网络拓扑随时间演化）

### 8. 不确定性量化创新 ★★★☆☆
**描述**：不只给点估计，给完整的分布/区间。
**示例**：
- 点预测 → 预测区间（bootstrap 置信区间）
- 确定性排序 → 概率排序（贝叶斯后验排名概率）
- "最优方案" → "稳健最优方案"（多情景下均表现好的方案）

---

## 策略 9-12：高难度（显著区分度）

### 9. 跨域迁移创新 ★★★★☆
**描述**：将一个领域的方法迁移到新领域应用。
**示例**：
- 生态学 Lotka-Volterra → 市场竞争模型
- 物理学 Ising 模型 → 舆论/投票/选址模型
- 流行病学 SIR → 信息传播/创新扩散模型
- 金融期权定价 Black-Scholes → 碳配额/排放权定价

### 10. 闭环/反馈创新 ★★★★★
**描述**：模型输出反馈影响输入，形成闭环系统。
**示例**：
- 选址 → 环境影响 → 重新评估选址（环境反馈闭环）
- 预测 → 策略干预 → 更新预测（政策效果闭环）
- 优化 → 灵敏度 → 重新约束 → 再优化（鲁棒闭环）

### 11. 博弈/多主体创新 ★★★★☆
**描述**：将单主体决策扩展为多主体博弈。
**示例**：
- 单方选址 → 多方博弈选址（NFL vs 城市政府 vs 环保组织）
- 单目标优化 → 多目标博弈（Pareto-Nash 均衡）
- 静态决策 → 序贯博弈（先发优势/后发优势分析）

### 12. 元模型/集成创新 ★★★★☆
**描述**：多个模型加权集成，比单一模型更稳健。
**示例**：
- AHP + TOPSIS + 灰色关联 → 三种方法集成排序
- ARIMA + XGBoost + LSTM → 时序预测集成（Bagging/Stacking）
- 不同城市的模型适配不同方法 → 元学习选择方法

---

## 创新选型指南

| 赛题特征 | 推荐创新策略 |
|---|---|
| 评价/排序题（如 HiMCM B） | 策略 1+2+7（组合+改进+自适应权重） |
| 优化题（如 CUMCM A） | 策略 5+9（混合模型+跨域迁移） |
| 预测题（如时间序列） | 策略 8+12（不确定性量化+集成预测） |
| 机理题（如传染病） | 策略 5+10（机理+数据驱动+闭环反馈） |
| 策略/政策题 | 策略 6+11（多层决策+博弈分析） |

## 创新声明模板

在论文摘要和模型评价中，按以下格式显式声明创新：

```
本文的创新点在于：
1. [理论创新] 将 XXX 方法与 YYY 方法首次结合，解决了 ZZZ 问题；
2. [方法创新] 对标准 AAA 算法做了 BBB 改进（具体改进），
   在 CCC 数据集上将 DDD 指标提升了 EEE%；
3. [应用创新] 首次将 FFF 领域的 GGG 方法迁移到 HHH 场景。
```

**⛔ 禁止**："本文具有创新性"（无具体内容）
**✅ 推荐**："本文通过引入碳排放强度归一化因子（kgCO2e/观众·日），
          首次实现了不同规模、不同时长赛事的环境影响可比性"
