# 10 — 数学建模实战优化技巧

提炼自《数学建模33讲：数学与缤纷的世界》（朱浩楠，2022）及竞赛实战经验。

---

## 核心哲学

> **没有"最优模型"，只有"追求更优"。**  
> 建模的本质不是找到完美答案，而是通过**假设→建模→检验→松绑→再建模**的螺旋上升，不断逼近更优解。

---

## 一、建模骨架：从简入繁五步法

### 第 1 步：最简假设 → 基础模型

**原则**：先做一个"能跑通"的最简模型，哪怕假设不现实。

```
示例（停车点选址）：
  假设 1: 道路是直线（化曲为直）
  假设 2: 每站只有 1 人
  → 建立简单的最优停车点模型
  → 发现：最优解始终在"中间"同学所在站点（中位数原理）
```

**竞赛应用**：第一版模型永远不要追求完美。先跑通 → 拿到基线结果 → 再迭代。

### 第 2 步：逐一松绑假设

**原则**：一次只松绑一条假设，观察结果变化。

```
松绑 1: 每站 1 人 → 每站多人（引入权重）
  目标函数变为: y = w₁|x-a| + w₂|x-b| + ...
  发现: 权重越大，最优解拉向该点越强

松绑 2: 6 站 → 5 站 → 4 站 → 3 站
  发现: 最优解始终在中间站——结论与站点数无关！
```

**竞赛应用**：在灵敏度分析部分展示"松绑假设 → 结果变化"的过程，这本身就构成论文的亮点。

### 第 3 步：寻找"与参数无关"的核心结论

**原则**：提炼出不受具体数值影响的规律。

> 如"最优停车点取决于中间同学所在站点，与各站间距无关"——这种结论最有价值。

**竞赛应用**：在摘要中强调这类结论。评委喜欢的不是"我们算出了 X=3.7"，而是"我们发现 X 总是落在区间 [a,b]，且与参数 c 无关"。

### 第 4 步：投回现实检验

**原则**：用模型结果反查假设合理性。

```
问题: 模型推荐的最优停车点在实际中是否可行？
  → 如果该点在人行道上 → 加约束"停车点需在机动车道上"
  → 重新建模
```

**竞赛应用**：在"模型评价—缺点"中不要写空话，而是指出"模型推荐 X 市但因数据缺失，实际可行性需验证"。

### 第 5 步：类比推广

**原则**：同一模型能否解决其他问题？

> 停车点模型 → 共享单车停放点 → 快递柜选址 → 公交站点优化

**竞赛应用**：论文最后一节"模型推广"如果能给出具体的迁移方案（而非"本模型可用于其他领域"的空话），直接加分。

## 二、数学技巧精选（来自《33讲》）

### 1. 利用概率分布简化计算

**技巧**：用"重心"概念替代"先求所有距离再加和求平均"。

> 计算三角形内随机两点平均距离 → 不需要二重积分，利用均匀分布的卷积得到三角形分布，再用"重心"简化。

**竞赛应用**：遇到"平均""期望"类计算，先想：能不能用分布的性质绕过繁琐求和？

### 2. 分离变量法解递推方程

**技巧**：当两个变量之间存在单向交换时，构建微分方程组 → 分离变量 → 独立求解。

> 两部之间药物浓度衰减 → dx/dt = -k₁x, dy/dt = k₁x - k₂y → 先解 x(t)，代入解 y(t)。

**竞赛应用**：多阶段/多仓室模型的递推关系→先找独立变量→逐步求解，不要一次性全耦合。

### 3. 等比数列逼近连续函数

**技巧**：等比数列赋值 → 极限 → 指数分布。  
几何平均（等比中项）的深层原理是等比数列对指数函数的离散逼近。

**竞赛应用**：做数量级估算时，几何平均比算术平均更稳定（不受极端值影响）。

### 4. 模糊分类代替硬分类

**技巧**：用正弦函数（或 Sigmoid）替代阈值截断，让分类边界"软化"。

> 传统：if score > 60: 及格
> 改进：及格概率 = 1/(1 + e^(-k(score-60)))

**竞赛应用**：评价模型中，避免"一刀切"的分类标准，用连续函数平滑过渡。

### 5. 二分类器组合实现多分类

**技巧**：N 个二分类器 → 可以区分 2^N 个类别。用进制思维理解分类器的组合能力。

**竞赛应用**：多类别问题 → OvR（一对多）或 OvO（一对一）策略 → `sklearn` 的 SVC 和 LogisticRegression 内置支持。

### 6. 不动点迭代简化复杂关系

**技巧**：连分式/自相似结构 → 不动点方程 → 迭代求解。

> √n 的连分式展开 → x = 1/(2 + x) 形式 → 不动点迭代 x_{k+1} = f(x_k)

**竞赛应用**：递归关系/自相似结构（如分形）→ 找不动点 → 避免直接求闭式解。

### 7. 初等推导 + 高等升华

**书中模式**：先用高中知识推一遍 → 再指出"这其实就是 XXX 定理的特例"。

> 余切公式的三维推广：先用初等几何推二维 → 再引向极小曲面（现代微分几何）。

**竞赛应用**：论文中展示"我们先用简单方法推演 → 发现这实际上是 XXX 定理的应用"——既显基础扎实又显理论深度。

## 三、论文优化技巧

### 1. 从具体中发现一般

❌ "我们建立了 AHP-TOPSIS 模型"（没新意）  
✅ "我们发现最优方案对 5 项指标中的 3 项不敏感——这意味着决策可以大幅简化"（有洞察）

### 2. 主动质疑自己的假设

在论文"模型缺点"中：
- ❌ "模型假设过于理想化"
- ✅ "假设 3（均匀分布）在城乡结合部不成立。用 2020 年人口普查数据检验：城内密度 CV=0.12（成立），郊区 CV=0.48（不成立）。修正方案：用人口加权密度替代均匀密度。"

### 3. 用"松弛"思路做灵敏度

不只做 ±20% 参数扰动——展示"放宽假设会怎样"：

| 假设 | 放宽方式 | 结果变化 | 结论稳定性 |
|---|---|---|---|
| 线性关系 | 用二次项检验 | R² 仅从 0.87→0.88 | 线性假设足够 |
| 正态分布 | 用 Bootstrapping | CI 从 [1.2,1.8]→[1.1,1.9] | 轻微变宽，结论不变 |

### 4. 数值结果"三步呈现"

每个关键结果按三步呈现：
1. **数字**：最优解 = 0.7637
2. **含义**：英格尔伍德以 76.4% 的贴近度排名第一
3. **洞察**：其优势来自 69% 可再生能源和最高公交分担率

## 四、竞赛常见低分陷阱

| # | 陷阱 | 为什么低分 | 如何规避 |
|---|---|---|---|
| 1 | 摘要空话连篇 | 评委只看摘要决定省一/省二 | 每问必须有具体数字 |
| 2 | 验证只做灵敏度 | 单点验证说服力弱 | ≥2 种验证方式（灵敏度+对照+交叉验证） |
| 3 | 假设不给依据 | 评委会问"为什么可以这样假设" | 每条假设给一句话依据 |
| 4 | 只报结果不解读 | 数字不解释等于没算 | 每个数字配一句"这说明了什么" |
| 5 | 图表无文字引用 | 图是孤立的 | 正文必须 \ref 每张图并解读 |
| 6 | 创新声明无对比 | "我们提出了新方法"不可信 | 必须有创新 vs 无创新的对比实验 |
| 7 | 结论超出模型范围 | "本模型适用所有场景"→明显夸大 | 明确模型的适用边界和限制条件 |
| 8 | 参考文献不规范 | 格式混乱表示不专业 | 统一用 GB/T 7714 或 APA 格式 |
