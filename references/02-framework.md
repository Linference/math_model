## 是否用 ML/DL —— 决策树
```
样本量小(<数百) ────────────────► 不用 DL；用可解释模型(回归/优化/统计)
        │
        └─ 样本充足
              │
   有明确机理 ─┼─► 机理模型为主(微分方程/优化)，ML 仅作对照/辅助
              │
   纯预测、特征多、非线性强 ─► 随机森林 / XGBoost / SVM（可解释性尚可，稳）
              │
   海量 + 图像/长序列/文本 ─────► 才考虑 CNN / LSTM / Transformer
```
判据三问：**数据量够不够、要不要可解释、有没有机理**。国赛重机理与可解释，DL 慎用且必须说清理由与防过拟合手段（交叉验证、正则、早停）。

## 稳 + 新
- 主线：一个稳妥、可解释、能拿基础分的模型。
- 增强：一个创新点（新方法/改进算法/多模型融合/更细的灵敏度分析）拿创新分。
