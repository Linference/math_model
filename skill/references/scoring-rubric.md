# scoring-rubric — 0–10 分评分量规

对齐对抗审稿的五维度。总分为五维加权（默认均权）。目标把基线 5.0 逼到 7.5+。

---

## 分档总览

| 分段 | 水平 | 特征 |
|---|---|---|
| 9.0–10 | 国一 | 模型新颖且严谨、结果充分验证、表达出色、有真创新 |
| 7.5–8.9 | 省一 | 模型合理、推导严谨、结果有验证、排版规范、有亮点 |
| 6.0–7.4 | 省二/三 | 基本合理但有短板（验证不足/表达一般/创新弱） |
| 5.0–5.9 | 基本完成 | 跑通了但有硬伤（假设牵强/结果无验证/图表乱） |
| <5.0 | 不合格 | 模型错、推导错、结果不可信 |

---

## 五维度评分细则（含具体锚点）

### 1. modeling — 建模合理性（权重 25%）

| 分数 | 锚点描述 | 判别标准 |
|---|---|---|
| **9-10** | 模型精准匹配问题本质，假设每条有据可查。选型有"为什么选 A 不选 B/C"的对比论证。 | 建模方案包含了备选方案排除理由 |
| **7-8** | 模型合理，假设基本成立。方法与问题类型匹配。 | 优化题用了优化方法，评价题用了评价方法——没犯方向性错误 |
| **5-6** | 模型基本可用但假设牵强。方法选型缺论证（只说"用 AHP"没解释为什么）。 | 方法能用但解释不够 |
| **<5** | 模型与问题不匹配（如优化题用了纯统计描述）。关键约束遗漏。 | 方法选型有方向性错误 |

### 2. rigor — 数学严谨性（权重 25%）

| 分数 | 锚点描述 | 判别标准 |
|---|---|---|
| **9-10** | 每步推导成立，关键结论有严格证明。最优性/收敛性/存在性交代清楚。所有公式编号可追溯。 | 无"显然""易证"跳过关键步骤 |
| **7-8** | 推导基本完整，主要结论有依据。关键公式含义清楚。无算术错误。 | 量纲正确、公式编号完整 |
| **5-6** | 推导有跳步。部分结论缺证明。"显然"背后有不成立的风险。存在轻微算术矛盾。 | 公式基本正确但有疏漏 |
| **<5** | 公式推导有明显错误。量纲矛盾。关键断言无证明且实际不成立。 | 存在硬伤 |

**具体检查清单**（评审时必须逐条核查）：
- [ ] 所有公式中的变量在符号说明表中定义
- [ ] 所有矩阵/向量维度在上下文一致
- [ ] 所有求和/积分范围明确
- [ ] 所有比值分子分母量纲一致
- [ ] AHP 类：CR < 0.1 且报告了 λ_max、CI、CR
- [ ] 优化类：交代了凸性/收敛性
- [ ] 统计类：报告了 p 值/置信区间

### 3. results — 结果与验证充分性（权重 25%）

| 分数 | 锚点描述 | 判别标准 |
|---|---|---|
| **9-10** | 结果正确且有多重验证（灵敏度+交叉验证+误差分析+对照）。结论有严格数据支撑，且讨论了不确定性。 | ≥3 种验证方式 |
| **7-8** | 结果正确，有灵敏度分析（±20% 参数扰动）和至少 1 种其它验证。 | ≥2 种验证方式 |
| **5-6** | 结果基本合理但验证不足（只做了灵敏度，没做交叉验证/对照）。 | 仅 1 种验证方式 |
| **<5** | 结果与常识矛盾、明显计算错误、前后不自洽、无验证。 | 结果不可信 |

**具体检查清单**：
- [ ] 灵敏度分析：关键参数 ±20% 扰动 → 输出变化 ≤ 合理范围
- [ ] 交叉验证：若用 ML → 有训练/测试分离或 k-fold
- [ ] 对照：至少与 1 个基准模型/基线方法对比
- [ ] 误差分析：报告了误差来源和量级估计
- [ ] 每个关键数字可追溯到代码输出（变量名+行号）

### 4. writing — 表达与图表规范（权重 15%）

| 分数 | 锚点描述 | 判别标准 |
|---|---|---|
| **9-10** | 摘要每问量化、结构完整、图表规范、语言严谨。摘要读完就知道做了什么、结果多少。 | 无"本文进行了深入研究"等空话 |
| **7-8** | 摘要含数字、结构完整、图表有编号和解读、参考文献规范。 | 每图被正文引用并解读 |
| **5-6** | 摘要空洞（缺数字）、部分图表无解读、符号未定义。 | 有格式缺陷 |
| **<5** | 摘要无量化、图表混乱、参考文献缺失。 | 格式问题影响阅读 |

**具体检查清单**：
- [ ] 摘要含 ≥4 个具体数字
- [ ] 每张图在正文被 `\ref` 引用且有 1-2 句解读
- [ ] 所有符号在符号说明表定义
- [ ] 表格用三线表（booktabs）
- [ ] 参考文献格式统一

### 5. innovation — 创新性（权重 10%）

| 分数 | 锚点描述 | 判别标准 |
|---|---|---|
| **9-10** | 方法原创或巧妙组合，视角独到，且通过对比证明了优势。 | 创新是有用的，不是为创而创 |
| **7-8** | 有明确的改进点或新颖组合，且有对比验证创新有效。 | "把 A+B 首次用于本问题"也算创新 |
| **5-6** | 有创新声明但缺对比说明优势。"创新"可能是包装旧方法。 | 声明了但没证明 |
| **<5** | 无创新，或伪创新（换个名字）。 | 纯套模板 |

---

## 评分锚点速查（评审时对照）

| 分数 | modeling | rigor | results | writing | innovation |
|---|---|---|---|---|---|
| **9** | 精准+有对比论证 | 严格证明 | 多重验证 | 量化摘要+规范 | 真有用创新 |
| **7** | 合理+匹配类型 | 完整+无错 | 有 2 种验证 | 结构完整 | 有改进点 |
| **5** | 基本可用 | 有跳步 | 仅 1 种验证 | 有缺陷 | 声明未证 |
| **3** | 不匹配 | 有算术错 | 结果矛盾 | 格式乱 | 无 |

---

## 综合评分计算

```
综合分 = modeling×0.25 + rigor×0.25 + results×0.25 + writing×0.15 + innovation×0.10
```

**特殊规则**：
- 如果 rigor < 5 → 综合分上限 6.0（数学错误是致命伤）
- 如果 results < 5 → 综合分上限 5.5（结果不可信全篇无意义）
- 如果任何一维 < 3 → 综合分上限 4.0

---

## 用法

每个评审子智能体按此打五维分与综合分。弱点定位到具体章节/公式/图，给可执行修法。复评时逐条核对是否已修。

评审输出格式：
```
综合分: X.X / 10
五维度: modeling=X, rigor=X, results=X, writing=X, innovation=X
High 弱点: [定位 + 问题 + 修法]
Medium 弱点: [...]
Low 弱点: [...]
needMoreExperiments: true/false
verdict: accept / revise / reject
```
