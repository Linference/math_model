## 是否用 ML/DL —— 决策树
```
样本量小(<数百) ────────────────► 不用 DL；用可解释模型(回归/优化/统计)
        │
        └─ 样本充足
              │
   有明确机理 ─┼─► 机理模型为主(微分方程/优化)，ML 仅作对照/辅助
              │
   纯预测、特征多、非线性强 ─► 随机森林 / XGBoost / SVM（可解释性尚可，稳）
              │
   海量 + 图像/长序列/文本 ─────► 才考虑 CNN / LSTM / Transformer
```
判据三问：**数据量够不够、要不要可解释、有没有机理**。国赛重机理与可解释，DL 慎用且必须说清理由与防过拟合手段（交叉验证、正则、早停）。

## 稳 + 新

**两线策略**：
- **主线（保底 60%）**：一个稳妥、可解释、能拿基础分的模型。
- **创新线（争 25%）**：1-2 个创新点，从 `09-innovation-playbook.md` 的 12 种策略中选取。

**创新选型速查**：
| 赛题类型 | 首选创新策略 | 次选 |
|---|---|---|
| 评价/排序 | 方法组合(1) + 改进(2) + 自适应权重(7) | 不确定性量化(8) |
| 优化 | 混合模型(5) + 跨域迁移(9) | 闭环反馈(10) |
| 预测 | 不确定性量化(8) + 集成(12) | 自适应(7) |
| 机理 | 机理+数据驱动(5) + 闭环(10) | 跨域迁移(9) |
| 策略/决策 | 多层(6) + 博弈(11) | 自适应(7) |

**创新验证铁律**：每项创新必须有对比实验证明其价值（创新 vs 无创新版本）。
