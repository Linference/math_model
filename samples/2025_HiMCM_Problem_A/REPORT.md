# 2025 HiMCM 问题 A：紧急疏散搜查 — 建模全过程报告

## §1 深度审题报告（阶段 1）✅ M1 PASS

### §1.1 问题背景与核心目标

在火灾、燃气泄漏等紧急情况下，训练有素的应急响应人员（responders，如消防员）需要对建筑物进行逐区域、逐房间的"清扫"（sweep），以确认所有人员已经安全撤离或正在向出口移动，目标是**确保无人遗漏**。这一过程的效率与策略直接关系到生命安全。

题目要求建立数学模型，优化多楼层建筑物在紧急疏散中的清扫策略。核心目标是在**最短时间内完成所有房间的清查**，同时兼顾**人员安全**与**响应者效率**。模型需要处理建筑布局的多样性（层数、楼梯位置、出口数量、房间用途）、响应者数量的可变性、紧急情况类型的差异（火灾、燃气泄漏等）、以及信息不完全和时间约束等现实因素。

**成功标准（评价维度）**：
1. 模型能输出最小清扫时间与最优路径/分配方案；
2. 模型具备泛化能力——可适应不同建筑布局、不同紧急情况类型；
3. 策略在速度、安全性与冗余度之间取得可论证的平衡；
4. 结论以可操作的形式呈现（致 LEPC 的信函）。

### §1.7 问题类型判定（⛔ 最关键！）

**主类型：组合优化 + 随机模拟（混合型）**

| 判定依据 | 说明 |
|---------|------|
| **依据 1（关键词）** | 全文反复出现"optimize""shortest possible time""optimal number""minimum time"——优化类问题标志 |
| **依据 2（问题结构）** | 目标函数（最短时间）+ 决策变量（人数、路径）+ 约束条件 → 优化问题完整范式 |
| **依据 3（输出形式）** | 数值型"最短时间"+ 方案型"最优路径/人数"——优化类典型输出 |
| **依据 4（图论/网络）** | 建筑天然映射为图 G=(V,E,w)，清扫本质为边/节点覆盖问题（CPP/mTSP 变体） |
| **依据 5（仿真）** | 时变危险、动态移动、通信延迟等需 Monte Carlo / Agent-Based 仿真处理随机性 |

**子问题数学域映射：**

| 子问题 | 主要数学域 | 关键工具 |
|--------|-----------|---------|
| 基本清扫路径规划 | 图论 + 组合优化 | 中国邮递员问题 (CPP)、多旅行商问题 (mTSP)、整数规划 |
| 时间估算 | 运动学 + 概率 | 步行速度模型、房间检查时间分布 |
| 不确定性建模 | 随机过程 + Monte Carlo | 烟雾扩散、人员行为概率、通信成功概率 |
| 多目标权衡 | 多目标优化 | 加权法、Pareto 前沿、目标规划 |
| 最优人员配置 | 资源分配 | 整数规划、边际分析 |

**策略要点**：
1. 用**图论建立建筑模型**：G = (V, E, w)，节点 = 房间/决策点，边权重 = f(距离、烟雾、拥挤)
2. 将总时间分解为：**行进时间 + 检查时间 + 楼梯时间 + 随机延迟**
3. 用 **Monte Carlo 模拟**处理不确定性，给出时间分布而非单点估计
4. 分别建立确定模型（快速估计下界）和随机模型（模拟现实），双侧印证

**典型错误（必须避免）**：
- ❌ 将建筑视为网格暴力搜索 → 无洞察
- ❌ 仅用手算或简单枚举 → 无模型
- ❌ 忽略图论的边权非齐性 → 简化过度

### §1.8 关键要素识别

#### 1. 房间"已清空"判定标准
- **目视确认**：响应者目视检查所有可见区域（包括门后、桌下、柜内）
- **听觉确认**：呼喊"有人吗？"并等待回应（烟尘中尤其重要）
- **热成像/技术辅助**：可穿透部分烟尘但非全部障碍物
- **交叉验证（冗余）**：若单人遗漏概率 p，双人独立检查遗漏概率降至 p²
- **时间戳记录**：记录清查时间，用于事后审计

#### 2. 房间类型/人员影响

| 类型 | 人员特征 | 检查时间倍乘 | 优先级 |
|------|---------|------------|-------|
| 儿童日托中心 | 儿童可能躲藏、无法自主疏散 | ×3.0 | 🔴 最高 |
| 办公室 | 成人，通常配合疏散 | ×1.0 | 🟡 标准 |
| 实验室 | 危险化学品 + 专业人员 | ×2.0 | 🔴 高 |
| 仓库 | 大空间、高货架、遮挡多 | ×2.5 | 🟠 中高 |
| 病房/医务室 | 行动不便者 | ×2.0 | 🔴 高 |

#### 3. 响应者数量与专业
- **基础**：消防员，会搜查但非建筑专家
- **最优**：混合团队——消防员（搜救）+ 安保（熟悉建筑）+ 医护人员
- **最少**：至少 2 人（安全规程"两人同行"原则）

#### 4. 冗余策略

| 策略 | 冗余度 | 时间增加 | 适用场景 |
|------|-------|---------|---------|
| 双人同查 | 高 | +100% | 高风险房间 |
| 交叉复查 | 中 | +30-50% | 复杂区域 |
| 标记系统 | 低 | +5% | 标准房间 |
| 主管确认 | 中 | +20% | 关键区域 |

#### 5. 紧急类型影响

| 类型 | 感知方式 | 安全窗口 | 主要影响 |
|------|---------|---------|---------|
| 火灾（有烟） | 火警/烟雾/高温 | 3-15 分钟 | 能见度↓、温度↑、结构风险 |
| 燃气泄漏 | 气味/探测器 | 不定 | 爆炸风险、需防静电 |
| 地震后 | 感知/警报 | 不定 | 余震、结构破坏、通道阻断 |
| 主动威胁 | 安保通报 | 不定 | 双重目标（搜索威胁+疏散） |

### §1.9 对后续阶段的指引

1. **模型构建必须始于图建模**：G=(V,E,w) 是第一步，不可跳过
2. **时间三分类不可混淆**：移动时间、清扫时间、协调时间分别建模
3. **问题二需精确解**：6 节点 2 代理，可用枚举或 0-1 整数规划精确求解
4. **问题三需有区分度的场景**：至少一个挑战垂直移动，一个挑战异质房间类型
5. **问题四随机性需认真对待**：Monte Carlo 多次运行报告均值+95%CI
6. **灵敏度分析是硬性要求**：核心参数 ±30% 扰动测试
7. **信函语言必须去技术化**：用日常语言传达策略

## §2 建模框架与方法选型（阶段 2）

### §2.1 问题类型驱动方法选择

基于 §1.7 判定——**主类型：组合优化 + 随机模拟（混合型 / Hybrid）**——对五个要求分别进行数学域映射与方法选型。

| 要求 | 子问题本质 | 数学域 | 主导方法族 |
|------|----------|--------|-----------|
| 要求 1 | 关键要素体系构建（定性→定量） | 领域分析 + 参数化 | 文献综合 + 分类矩阵 + 量化假设 |
| 要求 2 | 单层六室 / 双代理 / 最短时间清扫 | 图论 + 组合优化 + 运动学 | mTSP 变体 + 整数规划/穷举 + 时间分解模型 |
| 要求 3 | ≥2 个多楼层异构场景 / 可变代理数 | 组合优化 + 启发式 | GA / ACO + mTSP + 楼梯瓶颈建模 |
| 要求 4a | 不确定性 + 时变危险 + 通信延迟 | 随机过程 + Monte Carlo + 代理仿真 | 离散事件仿真 + 元胞自动机（烟雾）+ Pareto 多目标 |
| 要求 4b | 技术方案推荐 | 多准则决策 | 评分矩阵 + 简化 AHP |
| 要求 5 | 策略沟通（无需建模） | 科学传播 | 模型结果翻译为操作建议 |

**核心方法选型逻辑**：

```
Step 1: 建筑 → 图 G=(V,E,w)        【图论·networkx】
Step 2: 清扫 = 顶点/边覆盖问题      【mTSP 变体】
Step 3: 6节点 → 精确穷举            【整数规划 / 枚举】
Step 4: 20+节点 → 启发式            【GA + ACO 双算法对比】
Step 5: 不确定性 → Monte Carlo      【随机模拟】
Step 6: 多目标权衡 → Pareto 前沿    【加权法 + NSGA-II 对比】
```

### §2.2 ML/DL 决策

| 要求 | 是否 ML/DL | 理由 |
|------|-----------|------|
| 要求 1 | **不用** | 无历史数据，完全基于领域知识与文献；要素体系必须逻辑透明 |
| 要求 2 | **不用** | 组合搜索而非数据驱动；建筑拓扑确定、运动学方程确定、清扫SOP确定 |
| 要求 3 | **不用** | 仅3个设计场景不是"从样本学习"任务；GA/ACO收敛曲线、路径可视化均可透明展示 |
| 要求 4a | **不用（主模型）** | 每个样本由机理引擎生成，不是从数据中学规律；每个不确定性源必须用龙卷风图逐项量化 |
| 要求 4b | **不用** | 候选技术仅10-15项，5个评价维度——总评估矩阵仅75个单元格 |
| 要求 5 | **不用** | 无建模任务，纯科学传播 |

**总体结论**：无外部数据、机理明确、可解释性硬约束（应急响应策略必须可审计、可追溯）。

### §1.10.3 核心文献详评（6 篇）

**文献 1：Bagloee & Sarvi (2021) — Emergency Search Plan for Complex Premises** (ATRF 2021)
首次将消防员建筑搜索问题显式映射为"CPP + VRP"两阶段优化框架。**不足**：未建模房间内部清扫时间、仅单层、无烟雾时变影响。**与本题关系**：要求 2 的核心方法论起点，但房间服务时间、时变危险、冗余检查正是该文空白。

**文献 2：Wu & Chen (2012) — 3D Spatial Information for Fire-fighting Search and Rescue Route Analysis** (*Fire Safety Journal*, 48:21-29)
基于 3D GNM 的建筑搜救路径分析——Dijkstra 避烟、ACO 全遍历。**不足**：单代理、无动态烟雾。**与本题关系**：GNM 构建方法可迁移至图建模，需扩展为多代理+时变边权。

**文献 3：Nekovar, Faigl & Saska (2021) — Multi-Tour Set Traveling Salesman Problem** (*IEEE RA-L*, 6(4):7234-7241)
MS-TSP 形式化 + ILP 精确解 + GRASP 元启发式。**不足**：室外场景、无节点服务时间、代理同质。**与本题关系**：ILP 为要求 2 范式，GRASP 为要求 3-4 框架。

**文献 4：Lambert et al. (2021) — Search & Rescue Operations during Interior Firefighting: A Study into Crawling Speeds** (*Fire Safety Journal*, 121:103269)
84 名消防员全尺寸实验：12m²≈4min、爬行速率 15-21 m²/min、并排>串行。**与本题关系**：**关键参数来源**——为房间清扫时间和烟尘移动速度提供文献级别实证锚定。

**文献 5：Fang et al. (2026) — NIST Safe Step: An AI Model for Fire Evacuation Route Guidance** (*Journal of Building Engineering*)
RL 火灾疏散模型，FED 安全度量替代最短距离。**不足**：单层单代理、面向疏散者（exit-seeking）非响应者（room-covering）。**与本题关系**：要求 4b 关键参照——方向性差异需注意。

**文献 6：Lin et al. (2025) — Digital Twin of Buildings and Occupants for Emergency Evacuation** (*Advanced Engineering Informatics*, 66:103419)
PRISMA 综述 2004-2025，"感知→更新→仿真→决策"闭环，L0-L5 成熟度。**与本题关系**：技术全景地图，为要求 4b 提供成熟度评估准则。

| 空白 | 描述 |
