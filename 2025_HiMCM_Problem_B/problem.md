# 2025 HiMCM Problem B: 体育大型赛事的环境影响

## 赛题原文

### 背景

每年，超级碗（Super Bowl）将数百万人聚集在一起——从前往主办城市的球迷，到来自全球各地的观众。这一赛事产生了巨大的社会和经济价值，但同时也伴随着显著的环境代价。航空旅行、酒店住宿、能源使用、食品消费、废物产生以及大规模的转播运营，使得超级碗的环境足迹相当可观。

随着人们对可持续性的日益关注，像超级碗这样的大型体育赛事（体育大型赛事）正被要求更加环保。外部组织已经开发了模型和评分系统，根据能源使用、废物管理、交通和碳抵消等多种因素来评估这些大型赛事的可持续性。

尽管这些环境评分已经存在，且关于赛事策划者为环保所做的努力有大量数据可查，但可持续性很少成为决定赛事举办地点或设计配套基础设施的关键驱动因素。这种脱节为我们提供了一个机会：建立一个模型，使生态影响不再只是事后考虑，而是规划和选址决策的核心驱动力。设想这样一种场景：主办城市的评估不仅基于其经济可行性和球迷承载能力，还基于其可再生能源潜力、现有基础设施效率和交通可达性。这样的模型将使组委会能够以可衡量的方式平衡性能、成本和可持续性。

COMAP（Consulting Organization Making Athletics Planet positive）咨询公司聘请您的团队作为可持续发展顾问，评估并减少体育大型赛事的环境足迹。目标是理解这些赛事的生态影响，并探索赛事规划的变革如何能够带来积极改变。

### 要求

**1. 理解问题。** 以2025年在美国新奥尔良举办的超级碗LIX为基线，调查举办体育大型赛事的环境影响。
- 确定影响该赛事可持续性的领域，如能源消耗、水资源使用、废物产生、温室气体排放或其他环境影响。这些领域可以参考已有的评估超级碗LIX环境影响的评分指标。讨论如何利用这些指标帮助团队理解该赛事的真实环境足迹。
- 考虑这些影响在不同地点的差异。讨论环境影响如何因赛事地点而异，考虑气候、地理、交通基础设施、当地能源结构或其他当地环境因素。

**2. 建立模型。** 创建一个完全基于环境因素来决定下一届超级碗举办地点的模型。在构建模型时，团队应考虑什么驱动了环境影响，以及地点特定特征如何产生差异。模型可以是定性或定量的。

**3. 应用模型。** 确定哪个城市应在2029年举办超级碗（2029年是当前唯一未确认举办地点的年份）。
- (a) 美国共有19个城市曾经举办过超级碗。自NFL正式整合可持续性指标和环境影响评估以来，只有英格尔伍德（加利福尼亚州）、格兰岱尔（亚利桑那州）、拉斯维加斯（内华达州）和新奥尔良（路易斯安那州）举办过，圣克拉拉（加利福尼亚州）、英格尔伍德（加利福尼亚州）和亚特兰大（佐治亚州）计划在未来举办。从这些已举办过的城市中，确定哪个应再次举办。将您的模型应用于美国境内的潜在主办城市集合，确定哪个是最环保可持续的选择。
- (b) 关于从未举办过超级碗的城市的数据更难找到。考虑三个拥有NFL球队但从未举办过超级碗的潜在城市。应用您的模型，确定哪个是最环保可持续的选择。

**4. 扩展模型并反思分析。**
- (a) 扩展您的模型以适用于其他类型的体育大型赛事。修改模型以捕捉以下类型赛事选址的可持续性影响因素：
  - 单项锦标赛（如世界杯（任何运动）、美洲杯、F1大奖赛、高尔夫公开赛等）**或**
  - 综合运动会（如奥运会、英联邦运动会、Invictus Games、世界运动会等）
- (b) 将扩展模型应用于上述某类大型体育赛事，推荐一个合适的举办地点。通过解释模型如何支持您的结论并反映该更广泛赛事独特的可持续性挑战来证明您的选择。
- (c) 考虑基础设施投资、能源采购和交通方式的变化如何影响那些希望未来申办大型体育赛事的城市。确定帮助城市在短期内最小化环境影响的同时保持经济和后勤可行性的策略，以及如何影响这些城市因高可持续性评分而成为理想主办城市的长期竞争力。
- (d) 讨论在像超级碗这样的单场大型赛事与更大规模、多场地或综合运动会相比时，影响可持续性的最大环境因素。

**5. 分享模型与结果。** 给NFL写一封一到两页的信，推荐您选择的2029年超级碗主办城市。在信中，通过突出您提案的环境优势来说服组织接受您的选择。具体说明为什么您的首选城市脱颖而出，以及它如何与可持续发展目标保持一致。

### 术语表

- **体育大型赛事（Sport mega-events）** — 指具有重大经济、社会和环境影响的大型、高知名度体育赛事的总称。
- **组委会（Organizing committee）** — 负责赛事整体管理的专门组织，包括后勤、基础设施、利益相关者协调及其他规划工作。
- **单项锦标赛（Single-sport championship tournament）** — 专注于单一体育项目的竞技赛事，通过一系列结构化比赛决定冠军。
- **综合运动会（Multi-sport competition）** — 包含多种不同体育项目的组织化赛事，通常跨越多天、在不同场馆举行，参赛者来自不同地区或国家。
