# 2025_HiMCM_Problem_B — 建模过程记录

## 1 审题

### 1.1 背景与目标

超级碗（Super Bowl）是美国年度最大规模的体育赛事，每年吸引数十万球迷涌入主办城市，全球电视观众过亿。赛事涉及航空旅行、酒店住宿、场馆能耗、食品餐饮、废弃物处理、转播电力等大量资源消耗，碳足迹巨大。核心问题是**建立一个将环境可持续性作为选址决策核心驱动力的模型**，为NFL提供2029年超级碗主办城市的环保推荐。

### 1.2 逐问拆解

#### 问题1：理解问题
- **输出类型**：定性分析 + 分类讨论
- **子任务1A**：以2025年新奥尔良超级碗LIX为基线，识别环境可持续性多维度领域（能源消耗、水资源、废物产生、GHG排放等），引用已有环境评分指标体系。
- **子任务1B**：讨论环境影响如何随主办城市不同而变化（气候、地理、交通基础设施、当地能源结构）。
- **隐性约束**：需区分Scope 1/2/3排放；区分干旱与湿润地区的水资源影响权重。

#### 问题2：建立模型
- **输出类型**：决策模型（MCDM/优化/指数模型）
- **关键约束**：模型**完全基于环境因素**——经济因素不进入选址模型。
- **隐性约束**：模型需可泛化应用于多个城市；需考虑指标间相关性；NFL级别体育场为前提条件。

#### 问题3：应用模型
- **子任务3(a)**：从已举办过超级碗的19个城市中选最优。
- **子任务3(b)**：选3个有NFL球队但从未举办过超级碗的城市，评估最优。
- **隐性约束**：必须使用问题2的同一模型；2029年2月气候数据为关键（超级碗在2月举行）。

#### 问题4：扩展与反思
- **4(a)**：模型扩展至单项锦标赛或综合运动会（二选一）。
- **4(b)**：应用扩展模型推荐选址。
- **4(c)**：基础设施投资/能源采购/交通方式变化的策略分析。
- **4(d)**：单场赛事 vs 多场地综合赛事的最大环境因素对比。

#### 问题5：NFL推荐信
- **输出类型**：1-2页正式商业信函
- **隐性约束**：面向NFL决策者（非技术背景）；需体现对NFL Green Initiative的理解。

### 1.3 数据情况总览

- **题目直接提供数据**：无任何附件数据，为完全开放数据型赛题。
- **需自行收集**：超级碗LIX基线数据、各候选城市环境数据（电网、气候、交通、废物）、体育场数据、NFL球队城市列表、历史举办城市名单。

### 1.4 评分点推断

- 环境维度的完整性与科学性（引用真实评分体系如CRS、ISO 20121）
- 模型的合理性与可解释性（指标有依据，权重有逻辑）
- 模型实际运行的完整性和数据支撑
- 问题4扩展的深度与洞察
- 问题5信件质量（专业、有说服力）

### 1.5 常见陷阱

1. 模型混入经济指标 → 直接跑题
2. 漏掉Scope 3排放（观众航空旅行是最大碳源）
3. 候选城市集理解错误
4. 用年均温度代替2月温度
5. 模型推荐与信件推荐不一致
6. 忽略场地可行性（无穹顶+2月极寒）
7. 单位不统一（metric ton vs short ton）

### 1.6 问题间依赖

```
问题1 → 问题2（指标体系来自1A）→ 问题3a/3b → 问题5
                    ↓
              问题4a → 问题4b
问题2 + 认知 → 问题4c
全题认知 → 问题4d
```

## 2 框架/方法选型

### 2.1 整体技术路线

**核心框架**：GHG Protocol（Scope 1/2/3碳排放边界）贯穿全题。
**核心模型**：AHP（层次分析法）确定权重 + TOPSIS（逼近理想解排序法）综合排名。
**验证闭环**：灵敏度分析 + 熵权法对照 + Spearman秩相关。

**ML/DL总判断**：全程主线不用ML/DL。理由：候选城市仅19个（3a）+3个（3b），样本量远不足以支撑ML；MCDM可解释性强，完美匹配"完全基于环境因素"的约束。

### 2.3 指标体系草案（问题2核心）

**准则层**：能源与碳排放、水资源、交通出行、废物管理、气候适宜性、场馆绿色化

**指标层（12-18个）**：
1. 电网碳排放因子（kgCO2/kWh）
2. 可再生能源发电占比（%）
3. 2月平均温度（°C）
4. 2月取暖度日数（HDD）
5. 当地水资源压力指数
6. 城市废物回收率（%）
7. 体育场LEED/绿色建筑认证等级
8. 公共交通模式分担率（%）
9. 机场年客流量
10. 体育场距主要人口中心平均飞行距离
11. 人均绿地面积
12. 体育场是否有穹顶（0/1）
13. 碳抵消潜力（碳汇项目密度）

### 2.4 创新方向

1. **Scope 1/2/3体系化**：贯穿全文的碳排放边界框架
2. **碳抵消潜力修正项**：TOPSIS得分后的调整因子
3. **环境-气候联合适宜度指数（ECSI）**：二维决策矩阵
4. **城市环境改进潜力矩阵**：现状得分 vs 最大可改进空间
5. **排放强度归一化（kgCO2e/观众·日）**：跨赛事类型可比性

### 4.3 结果解读

1. **西雅图是意外赢家** — 69%可再生能源(水电为主)、最高公交分担率(5.7%)、最高回收率(56%)、最低水资源压力(0.5)，验证了"环境因素应驱动选址决策"的核心命题。

2. **模型稳健** — ±20%权重扰动下英格尔伍德排名不变；情景分析中前3保持稳定。

3. **奥运会扩展成功** — 伦敦因2012奥运遗产场馆、45%公交分担率、45%回收率排名第一。

4. **结构性洞察** — 超级碗将大规模Scope 3排放在单日集中爆发；奥运会虽总量大但有建设碳债务且时间跨度分散。
